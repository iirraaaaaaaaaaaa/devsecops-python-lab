# Внедрение практик безопасности в CI/CD-конвейеры (DevSecOps)

## Описание задания

Цель задания — познакомиться с практиками DevSecOps и научиться интегрировать автоматизированные проверки безопасности в процесс разработки программного обеспечения.

Для выполнения задания необходимо выбрать небольшой существующий Python-проект или создать собственный. Проект должен позволять настроить автоматизированные проверки качества и безопасности кода и продемонстрировать обнаружение и устранение выявленных проблем.

Необходимо настроить CI-конвейер на базе GitHub Actions, подключить инструменты статического анализа кода и проверки зависимостей, проанализировать выявленные проблемы и устранить их.

В качестве инструментов рекомендуется использовать Pylint, Bandit и pip-audit. Допускается применение аналогов с сопоставимой функциональностью.

## Требования к окружению

- Python (версия выбирается студентом с учетом совместимости проекта и инструментов).
- Аккаунт GitHub.
- Доступ к GitHub Actions.
- Редактор кода (например, VS Code).

## Подготовка проекта

1. Выбрать небольшой существующий Python-проект или создать собственный.
2. Разместить проект в личном GitHub-репозитории.
3. Создать изолированное окружение (например, с помощью venv).
4. Установить необходимые зависимости.
5. Убедиться, что проект запускается локально.

## Локальный запуск проверок

Необходимо обеспечить возможность локального запуска выбранных инструментов анализа и тестирования.

Рекомендуемые инструменты и пример команд:

```bash
python -m pytest
python -m pylint src
python -m bandit -r src
python -m pip_audit -r requirements.txt
```

Команды приведены для примера. Допускается использование других инструментов. Студент должен указать в своем README.md точные команды, необходимые для запуска проверок в выбранном проекте.

## Ожидаемый результат

После выполнения задания должны быть получены:

- GitHub-репозиторий с настроенным CI-конвейером.
- Автоматический запуск проверок при push и pull request.
- Результаты выполнения тестов и security-проверок.
- Исправления обнаруженных проблем.
- Краткий отчет с описанием проблем, способов их устранения и результатов повторных проверок.

## Формат сдачи

Предоставить ссылку на GitHub-репозиторий с исходным кодом, конфигурацией GitHub Actions, историей запусков конвейера и отчетом `REPORT.md`.
Видеоролик с демонстрацией работы (до 4х минут) загрузить на Яндекс/Гугл Диск с доступом по ссылке. Ссылку на видеоролик разместить в `REPORT.md`.
