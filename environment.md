## Изолированность окружения

Для выполнения задания используется виртуальное окружение Python (`venv`), позволяющее устанавливать зависимости проекта независимо от глобального окружения пользователя.

Все необходимые библиотеки указываются в файлах `requirements.txt` и `requirements-dev.txt` с зафиксированными версиями.

Локальные проверки и проверки в GitHub Actions должны выполняться в совместимом окружении с одинаковой версией Python и набором зависимостей.

Проект не требует платных сервисов, внешних баз данных или дополнительных инфраструктурных компонентов.
