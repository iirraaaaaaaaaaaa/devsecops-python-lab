## Изолированность окружения

Студент самостоятельно выбирает способ изоляции окружения Python (например, venv, Poetry или uv).

Выбранный способ должен обеспечивать установку зависимостей без конфликтов с глобальным окружением пользователя.

Необходимо:

1. Зафиксировать используемую версию Python.
2. Указать зависимости проекта и инструментов анализа.
3. Обеспечить воспроизводимую установку зависимостей, предпочтительно с использованием зафиксированных версий или lock-файла.
4. Обеспечить выполнение проверок как локально, так и в GitHub Actions.
5. Документировать команды подготовки окружения и запуска проверок.

Локальные проверки и GitHub Actions должны использовать согласованные версии Python и зависимостей.

Допускается использование любых бесплатных инструментов, обеспечивающих выполнение указанных требований.
